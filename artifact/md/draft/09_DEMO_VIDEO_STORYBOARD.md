# 시연영상(UCC) 3분 스토리보드

## 1. 콘셉트

주제: "지도에서 찾고, AI에게 물어보고, 계약 전 위험을 확인한다."  
권장 길이: 2분 50초-3분 10초  
권장 구성: 실제 화면 녹화 + 짧은 자막 + 내레이션

## 2. 타임라인

| 시간 | 화면 | 동작 | 내레이션/자막 |
| --- | --- | --- | --- |
| 0:00-0:10 | 로고/메인 진입 | 살만해 로고와 지도 화면 표시 | "계약 전, 이 집이 정말 살 만한지 확인하는 서비스, 살만해입니다." |
| 0:10-0:35 | 지도 탐색 | 지도 위 다크 네이비 지역 평균 마커와 `200개 지역` 표시 | "지도에서는 현재 화면 안의 지역 평균과 매물 묶음을 한눈에 확인할 수 있습니다." |
| 0:35-0:55 | 필터 적용 | 검색창, 거래/유형/보증금/매매가 필터 보여주기 | "거래 유형, 주택 유형, 가격 조건을 바꿔 현재 지도 범위를 다시 조회합니다." |
| 0:55-1:10 | 우측 패널 | `F-1 Property Search`, `지도 범위 매물`, 빈 상태 안내 표시 | "확대 전에는 상세 매물 대신 지역 평균과 매물 묶음을 지도에 표시합니다." |
| 1:10-1:35 | 로그인 | 헤더 `챗봇` 클릭 → 로그인 화면 → 로그인 | "AI 상담은 로그인 후 사용할 수 있고, 인증은 Spring Security JWT로 처리합니다." |
| 1:35-1:50 | 챗봇 진입 | 로그인 후 다시 헤더 `챗봇` 클릭 | "로그인 후 챗봇 화면에서 예시 질문과 입력창을 확인할 수 있습니다." |
| 1:50-2:15 | AI 질문 | 예시 질문 `확정일자는 언제 받아야 하나요?` 클릭 | "사용자는 계약 전 궁금한 내용을 자연어로 질문할 수 있습니다." |
| 2:15-2:35 | 챗봇 응답 | 사용자 bubble, AI 응답 카드, 다시 생성/복사/공유/저장 버튼 표시 | "응답은 대화형 카드로 표시되고, 다시 생성이나 저장 같은 액션을 제공합니다." |
| 2:35-2:45 | 기능 설명 컷 | PPT 또는 다이어그램으로 RAG/시세/안전 분석 구조 삽입 | "내부적으로는 질문 의도에 따라 매물 검색, 법률 RAG, 시세·안전 분석 워커가 동작하도록 설계했습니다." |
| 2:45-3:00 | 아키텍처 요약 이미지 | PPT의 아키텍처 다이어그램 삽입 | "프론트는 Spring Boot만 호출하고, AI와 벡터 검색은 FastAPI backend-ai에서만 수행하도록 분리했습니다." |
| 3:00-3:10 | 마무리 | 메인 화면/로고 | "살만해는 매물 탐색을 넘어 계약 전 판단을 돕는 AI 부동산 에이전트입니다." |

## 3. 촬영 체크리스트

| 항목 | 체크 |
| --- | --- |
| 로컬/배포 서버가 정상 실행되는지 확인 |
| 네이버지도 API 키와 backend API 환경변수 준비 |
| 데모 계정 로그인 정보 준비 |
| 챗봇 질문 3개를 미리 복사해두기 |
| AI 응답 지연에 대비해 컷 편집 또는 속도 조정 준비 |
| 커뮤니티/HUG 등 MVP 제외 기능은 핵심 시연에서 과하게 보여주지 않기 |
| 직접 `/chat` URL로 진입하지 말고 루트에서 헤더 네비게이션으로 이동하기 |
| 로그인 후 자동 redirect가 안 되면 다시 `챗봇` 버튼을 클릭하기 |
