## 3. 배포 시연 접근 순서

1. `https://salmanhae.vercel.app/`로 진입한다.
2. 지도 화면에서 검색창, 거래/유형/가격 필터, 지역 평균 마커, 우측 `지도 범위 매물` 패널을 보여준다.
3. 챗봇 시연은 헤더의 `챗봇`을 클릭해 로그인 화면으로 이동한다.
4. 데모 계정으로 로그인한 뒤 루트 화면으로 돌아오면 다시 `챗봇`을 클릭한다.
5. 챗봇 화면에서 예시 질문, composer, 메시지 bubble, 메시지 액션 버튼을 보여준다.

주의: 현재 배포 환경에서는 `/login`, `/chat` 직접 URL 진입이 404가 될 수 있으므로 발표 중에는 반드시 루트 URL에서 네비게이션으로 이동한다.

## 4. 우수 PPT 참고 보강 포인트

우수 PPT 예시는 `기획 배경 → 시스템 설계 → 시연 영상 → 주요 기능 Page Flow → 고도화 적용 방안 → 기대 효과` 흐름이 강하다. 살만해 발표도 아래 두 섹션을 추가하면 문서형 목차보다 실제 발표형 구조에 가까워진다.

### 4.1 Page Flow 추가 권장

| 흐름 | 보여줄 화면 | 메시지 |
| --- | --- | --- |
| 지도 홈 | 배포 지도 화면, 검색/필터, 지역 평균 마커 | 비로그인도 지도 기반 시세 탐색 가능 |
| 로그인 가드 | 챗봇 클릭 → 로그인 화면 | AI 상담은 인증 후 사용 |
| 챗봇 홈 | 예시 질문 4개, 하단 composer | 계약 전 질문을 자연어로 입력 |
| AI 응답 | 사용자 bubble, AI 응답 카드, 액션 버튼 | 답변을 대화형 카드로 확인하고 저장/공유 가능 |
| 분석 구조 | 실제 화면 + Agent 흐름도 | 화면 뒤에서 worker가 매물/법률/시세/안전을 분기 처리 |

### 4.2 고도화 적용 방안 추가 권장

| 기술 포인트 | 문제 | 해결 | 결과 |
| --- | --- | --- | --- |
| LangGraph Supervisor Agent | 질문이 매물/법률/시세/안전으로 복합적임 | supervisor가 worker를 순차 선택하고 `workersCalled`로 추적 | 단일 챗봇보다 설명 가능한 AI 처리 흐름 확보 |
| pgvector 법률 RAG | 법률 답변은 근거 없는 일반 답변이 위험함 | 법률 chunk embedding을 검색해 근거 카드 기반 응답 생성 | 임대차 법률 상담의 신뢰도 강화 |
| 배치 기반 데이터 적재 | 공공 API를 요청 때마다 호출하면 느리고 불안정함 | 실거래가/안전시설을 배치로 DB 저장 | 지도/분석 API 응답성 개선 |
| 안전 점수 사전 계산 | 매번 반경 시설을 계산하면 비용 증가 | `property_score_stat`에 매물별 점수와 시설 수 저장 | 챗봇/상세 화면에서 빠른 안전 분석 가능 |
| 지도 viewport 모드 | 전국 매물을 한 번에 렌더링하면 화면이 혼잡함 | zoom별 지역 평균, 클러스터, 개별 매물 모드 분리 | 사용자가 단계적으로 정보를 탐색 가능 |

## 5. 발표 문장 초안

> 살만해는 단순히 매물을 보여주는 서비스가 아니라, 계약 전에 사용자가 궁금해하는 "이 집이 정말 살 만한가"를 지도와 AI 에이전트로 함께 검증하는 서비스입니다.

> 사용자는 비로그인 상태에서도 지도에서 매물과 지역 평균을 확인할 수 있고, 로그인 후에는 AI 챗봇에게 자연어로 매물 추천, 법률 상담, 시세와 안전 분석을 요청할 수 있습니다.

> 아키텍처는 Vue 프론트엔드, Spring Boot API, FastAPI 기반 LangGraph AI 서버로 분리했습니다. 프론트엔드는 Spring Boot만 호출하고, LLM과 pgvector 검색은 backend-ai에서만 수행하도록 경계를 나눴습니다.

> 공공 API는 사용자가 요청할 때마다 호출하지 않고 배치로 수집해 DB에 저장합니다. 안전 점수도 미리 계산해 `property_score_stat`에 저장하므로 지도와 챗봇 응답에서 안정적으로 사용할 수 있습니다.

## 7. AI 사용 보고서 포함 항목

| 항목 | 작성 내용 |
| --- | --- |
| AI 사용 목적 | 매물 추천, 법률 상담, 시세/안전 분석 답변 생성 |
| Agent 설계 | LangGraph supervisor가 worker를 순차 선택하고 `workersCalled`를 누적 |
| 프롬프트 전략 | 법률 RAG 근거 카드 기반 답변, 분석 metric 기반 한국어 설명 |
| 데이터 관리 | 법률 chunk embedding은 pgvector, 공공 데이터는 배치 후 DB 저장 |
| 안전장치 | Spring Boot는 LLM을 직접 호출하지 않고 backend-ai 내부 API만 호출 |
