# 살만해 제출 산출물

## 현재 구조

| 경로 | 내용 |
| --- | --- |
| `logo/` | 기존 살만해 로고 파일. 변경하지 않음 |
| `md/` | 제출 산출물 Markdown 최종본과 초안 보관 |
| `md/draft/` | 기존 제출 산출물 초안 |
| `screenshots/` | 배포 페이지 기준 화면 캡처 |
| `wbs & gantt/` | 기존 WBS/Gantt 엑셀 산출물 |
| `usecase & design/` | 기존 UseCase/Screen Design PDF 산출물 |

## Markdown 산출물

현재 최종 Markdown은 `md/` 아래에 정리합니다.

- `md/02. UseCase Diagram.md`
- `md/03. WBS.md`
- `md/04. ERD.md`
- `md/05. API설계서.md`
- `md/06. Class Diagram.md`

기존 초안 인덱스와 참고 명세/평가표 대응은 `md/draft/00_INDEX.md`, `md/draft/10_REFERENCE_ALIGNMENT.md`에 보관했습니다.

배포 화면 기준 캡처:

- `screenshots/deployed-map.png`
- `screenshots/deployed-chat.png`
